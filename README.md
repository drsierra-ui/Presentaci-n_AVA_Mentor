## Publicacion en GitHub Pages

1. Cree un repositorio publico en GitHub, por ejemplo `ava-mentor-presentacion`.
2. Suba los archivos `index.html`, `.nojekyll` y `README.md` a la **raiz** del repositorio (no suba el ZIP directamente).
3. Abra **Settings > Pages**.
4. En **Build and deployment**, seleccione **Deploy from a branch**.
5. Seleccione la rama **main** y la carpeta **/(root)**, y guarde.
6. Cuando GitHub muestre **Visit site**, abra la pagina publicada.

La URL habitual sera `https://USUARIO.github.io/ava-mentor-presentacion/`.
